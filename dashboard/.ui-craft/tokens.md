# CryptoShield — Token Spine

## 1. Surface & Neutral Ramp (Cyber Dark `#0B0F19`)
- `--bg-canvas`: `#0B0F19` (Primary viewport background)
- `--bg-surface`: `#0F172A` (`slate-900` — Primary panel surface)
- `--bg-elevated`: `#131C31` (Subtle elevated header/footer strip)
- `--border-subtle`: `rgba(30, 41, 59, 0.85)` (`slate-800` hairline divider)
- `--border-strong`: `rgba(51, 65, 85, 0.9)` (`slate-700` interactive control border)

## 2. Semantic Risk Palette (Mandatory Contract)
- **SAFE (Green):** Indicator `bg-emerald-500`, Text `text-emerald-400`
- **WARNING (Amber):** Indicator `bg-amber-500`, Text `text-amber-400`
- **DANGER / CRASH (Red):** Indicator `bg-rose-600`, Text `text-rose-400`, Subtle Glow `shadow-[0_0_28px_-6px_rgba(225,29,72,0.4)]`

## 3. Typography & Numeric Discipline
- **UI Sans:** `IBM Plex Sans` (400, 500, 600) — Sentence case headings (`tracking-tight`), compact 13–14px body.
- **Data Mono:** `IBM Plex Mono` (400, 500, 600) — `font-variant-numeric: tabular-nums slashed-zero` on all prices, percentages, timestamps, cluster IDs, and ratios.

## 4. Radius & Spacing Scale
- **Spacing:** Strict 4/8px scale (`4px`, `8px`, `12px`, `16px`, `20px`, `24px`).
- **Radii:** `6px` (`rounded-md`) for buttons/inputs/segmented tabs; `10px` (`rounded-[10px]`) for top-level panels.
